# PocketSmart AI
SmartBridge Project 1 — PocketSmart AI: Your Smart Budget & Recommendation Assistant.

## Stack
Python, Flask, Google GenAI SDK, Gemini, HTML, CSS, JavaScript.

## Run
1. `python -m venv .venv`
2. Activate the environment.
3. `pip install -r requirements.txt`
4. Copy `.env.example` to `.env`.
5. Put your Gemini API key in `.env`.
6. `python app.py`
7. Open `http://127.0.0.1:5000`

Never upload `.env` or your API key to GitHub.
