# PocketSmart AI — SmartBridge 8-Phase Submission

## Phase 1 — Brainstorming & Ideation
Problem: Users may struggle to organize income, expenses and savings goals.
Solution: A Gemini-powered budgeting assistant.
Objective: Provide simple AI-assisted budget analysis and practical suggestions.

## Phase 2 — Requirement Analysis
Functional: income input, expense input, savings goal, AI analysis, questions, reset.
Non-functional: usability, reliability, responsive UI, maintainability and API-key security.

## Phase 3 — Project Design
User → Web UI → Flask Backend → Gemini API → AI Analysis → Web UI.

Modules: UI, backend, Gemini integration, result display and configuration/security.

## Phase 4 — Project Planning
Select project → design → develop UI → integrate Gemini → test → document → demo.

Suggested team roles: coordinator/documentation, frontend, backend/AI integration, testing/demo.

## Phase 5 — Project Development
Implemented using Flask, HTML/CSS/JavaScript and the Google GenAI SDK.

## Phase 6 — Project Testing
Test valid inputs, empty input, missing API key, API/network errors, reset function and mobile layout.

## Phase 7 — Project Documentation
Document objective, architecture, technologies, features, limitations and future enhancements.

## Phase 8 — Project Demonstration
Show project title, purpose, benefits, enter sample budget data, run analysis, ask a follow-up question and show final output.
